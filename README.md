# Homebrew tap for Folio

[Folio](https://github.com/lulu-loopp/folio-terminal) is a terminal for macOS and Windows: formulas typeset where a command prints them, files previewed beside the prompt, and an agent that is waiting for you says so.

```sh
brew install --cask lulu-loopp/folio/folio
```

The cask installs the signed and notarized `Folio.app` from the release page. Apple silicon, macOS 14 or newer.
